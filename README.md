# Number Guessing Game

A beginner-friendly command-line game written in Python where the player tries to guess a randomly generated number between 1 and 20.

## How It Works
- The program generates a secret integer between `1` and `20` using Python's `random` module.
- The player enters guesses in the terminal and receives `"Too low!"` or `"Too high!"` hints after each try.
- Once the correct number is guessed, the game displays the total number of attempts taken.

## How to Run
```bash
python3 game.py
